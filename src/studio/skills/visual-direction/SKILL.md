# Visual Direction
## Use When
Setting a visual system before detailed layout or motion execution.
## Inputs
Communication objective, audience, approved strategy, and medium constraints.
## Process
Define objective, audience, emotional target, concept, hierarchy, composition, typography, color, imagery, texture/material, consistency rules, and medium constraints.
## Output
A visual concept with rationale and a handoff-ready direction system.
## Validation
Check strategic alignment, hierarchy, clarity, distinctiveness, and cross-medium consistency.
## Avoid
Unexplained aesthetic keywords or production details without a visual rationale.
